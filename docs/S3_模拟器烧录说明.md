# T-Display-S3 模拟发射板 烧录说明（v2.7.0）

v2.7.0 起固件同时支持两块板，由编译目标 `CONFIG_IDF_TARGET` 自动切换：

| 板子 | 目标 | LCD 接口 | 用途 | 默认构建 |
|------|------|----------|------|----------|
| T-Display-C5 | esp32c5 | SPI | 侦测 | detector（CI 产出 `firmware-c5-detector`）|
| T-Display-S3 | esp32s3 | I8080 8 位并口 | 模拟发射 | simulator（CI 产出 `firmware-s3-simulator`）|

## S3 引脚（代码自动选择，无需手动改）
- 数据 D0..D7：GPIO39/40/41/42/45/46/47/48
- WR=8, RD=9, DC=7, CS=6, RST=5, BL=38
- **GPIO15 = 外设电源使能，固件已自动置高**（不置高整板黑屏）
- 按键：BOOT=GPIO0（B 键），USER=GPIO14（A 键）
- 电池电压：GPIO4 ADC1_CH3（1:2 分压）

## 本地编译 S3 模拟器固件
```bash
. $HOME/esp/esp-idf/export.sh
cd rid-scanner-c5
cp sdkconfig.defaults.s3 sdkconfig.defaults
idf.py set-target esp32s3
idf.py build
```
产物：`build/remoteid_scanner.bin`

## 烧录（首次刷 S3）
S3 bootloader 偏移是标准的 0x0，整板烧录用：
```bash
python -m esptool --chip esp32s3 --port COM3 --baud 921600 write-flash \
  0x0 build/bootloader/bootloader.bin \
  0x8000 build/partition_table/partition-table.bin \
  0x10000 build/remoteid_scanner.bin
```
> 注意：S3 bootloader 在 **0x0**，和 C5 的 0x2000 不一样。首次刷必须三段全刷。
> 之后日常更新只刷 app：`0x10000 remoteid_scanner.bin`。

## 与 C5 侦测板配合
- C5 刷 `firmware-c5-detector`，跑侦测。
- S3 刷 `firmware-s3-simulator`，开机进入待机（不自动发射），按 B 键启动/暂停模拟发射。
- 两块板物理隔离，互不干扰，彻底避免 v2.5.x 模拟器链接导致的侦测共存 bug。
